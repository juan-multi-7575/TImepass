# Deep-Dig Checklist: browser-use

Subagents MUST append one line per dig here (do not overwrite others lines, only append).
Format: `- [x] <agent-name> | <feature> | <files dug> | <one-line finding>`

- [x] agent-dom-service | DOM/element serialization, clickability/visibility, index<->element mapping | dom/service.py, dom/serializer/serializer.py, dom/serializer/clickable_elements.py, dom/enhanced_snapshot.py, dom/views.py | DOMSerializerTree folds 4 parallel CDP trees (DOMSnapshot/DOM.getDocument/AX/DPR) into EnhancedDOMTreeNode, scores visibility & clickability, then assigns backendNodeId-as-index selector_map; actions click by re-resolving that index through the cached selector map over CDP.
- [x] agent-agent-loop | core Agent loop | browser_use/agent/service.py, agent/views.py, agent/message_manager/{service,views}.py, tools/{service,registry/service}.py, agent/prompts.py, browser/session.py | run()-loop drives per-step LLM plan via dynamic AgentOutput schema, executes through multi_act->Tools.act->Registry, folds ActionResult memory into a single state_message, and terminates only via done/is_done, max_steps, or max_failures (no backtracking).
- [x] agent-browser-session | Browser/Session layer (launch, CDP connect, lifecycle, proxy/stealth, tab switch) | browser/session.py, browser/session_manager.py, browser/profile.py, browser/watchdogs/local_browser_watchdog.py, browser/_cdp_timeout.py, browser/events.py | BrowserSession is the single CDP/EventBus hub: SessionManager is sole source of truth for targets/sessions (fed by CDP attach/detach/targetInfoChanged/lifecycle events), LocalBrowserWatchdog launches Chromium on a free debug port, agent_focus_target_id drives all tab routing, with auto-recovery of stale focus and auto-reconnect of dropped WebSockets.
